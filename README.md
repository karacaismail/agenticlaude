# agenticlaude

Fabrika Karar Merkezi: Plane, ajanlı geliştirme, GitHub CI/CD ve alpha ortamından oluşan akış için kararlar ve her kararın dayandığı kaynaklı bulgular.

Site: https://karacaismail.github.io/agenticlaude/

## İçerik

- `fabrika-karar-merkezi/`: uygulamanın kaynağı (React, Mantine, TypeScript, SCSS, Vite) ve tek dosyalık derlemesi `fabrika-karar-merkezi.html`.
- `mimari-haritasi/`, `risk-haritasi/`, `arac-haritasi/`, `ihtiyac-haritasi/`, `agentic-stack-docs/dist/`, `agentic-stack-report-2026-09-23/rapor.html`, `devir-teslim/DEVIR-TESLIM.md`: sayfanın bağlantı verdiği ve veri betiklerinin okuduğu dosyalar.

## Yeniden derleme

```bash
cd fabrika-karar-merkezi
npm ci
npm run build
```
